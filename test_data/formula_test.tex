\section*{Quantum transport test}
For a one-dimensional wave packet, the normalized state is
\[
\psi(x,t)=\frac{1}{(2\pi\sigma_t^2)^{1/4}}
\exp\!\left[-\frac{(x-x_0-vt)^2}{4\sigma_t^2}
        +\frac{i}{\hbar}\left(p_0x-\frac{p_0^2t}{2m}\right)\right],
\qquad
\sigma_t=\sigma_0\sqrt{1+\left(\frac{\hbar t}{2m\sigma_0^2}\right)^2}.
\]
The measured error for three discretizations is shown below.
